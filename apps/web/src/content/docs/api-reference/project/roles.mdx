## Grant a project-created role to a member

<Endpoint method="PUT" path="/api/servers/{serverId}/members/{discordId}/roles/{roleId}" />

Grants a role to a member of the server. Only roles previously created by the calling project can be granted; attempts to grant executive, root, or unowned roles will return 403 Forbidden and record an audit log.

**Authentication:** Project API key (`X-API-Key` header)

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serverId` | path | `string` | yes | Discord server ID |
| `discordId` | path | `string` | yes | Discord member ID |
| `roleId` | path | `string` | yes | Discord role ID to grant |

**Responses**

| Status | Description | Body |
| --- | --- | --- |
| `204` | Role granted successfully (or already held) |  |
| `401` | Missing or invalid API key |  |
| `403` | Project lacks manage_roles scope, role was not created by this project, or role is protected |  |
| `404` | Server, member, or role not found |  |

## Create a Discord role for an event or project

<Endpoint method="POST" path="/api/servers/{serverId}/roles" />

Creates a new Discord role with no permissions by default (0n bitfield) and records project ownership. The role can subsequently be granted and removed by the same project using the member role endpoints.

**Authentication:** Project API key (`X-API-Key` header)

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serverId` | path | `string` | yes | Discord server ID |
