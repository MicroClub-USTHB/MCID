Discord webhook creation and management, authenticated with a project API key

## List webhooks for a project

<Endpoint method="GET" path="/api/projects/{projectId}/webhooks" />

Returns the webhooks owned by the requesting project. Channel and server names are resolved from the bot cache and may be null.

**Authentication:** Project API key (`X-API-Key` header)

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID (must be the requesting project) |
| `serverId` | query | `string` | no | Filter by Discord server ID. The project must have access to that server. |
| `limit` | query | `number` | no | Max number of webhooks (1-100) Default: `50`. |
| `offset` | query | `number` | no | Pagination offset Default: `0`. |

**Responses**

| Status | Description | Body |
| --- | --- | --- |
| `200` | List of webhooks. | `WebhookListResponseDto` |
| `400` | Invalid query parameters. |  |
| `401` | Missing or invalid API key. |  |
| `403` | The serverId filter names a server the project cannot access. |  |
| `404` | Project not found for this API key. |  |

## Create a webhook for a channel

<Endpoint method="POST" path="/api/servers/{serverId}/channels/{channelId}/webhooks" />

Creates a Discord webhook in the channel and stores it for the project. The webhook URL and token are encrypted at rest and never returned.

**Authentication:** Project API key (`X-API-Key` header)

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serverId` | path | `string` | yes | Discord server ID |
| `channelId` | path | `string` | yes | Discord channel ID |

**Request body** (JSON, required): [CreateWebhookDto schema](#createwebhookdto-schema).

**Responses**

| Status | Description | Body |
| --- | --- | --- |
| `201` | Webhook created. | `WebhookCreatedResponseDto` |
| `400` | Invalid name or avatar. |  |
| `401` | Missing or invalid API key. |  |
| `403` | Project does not have MANAGE_WEBHOOKS operation on this server. |  |
| `404` | Channel does not exist or bot lacks access. |  |
| `409` | Project webhook limit reached. |  |
| `502` | Discord API error. |  |
