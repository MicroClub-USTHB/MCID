## Create a Discord scheduled event

<Endpoint method="POST" path="/api/servers/{serverId}/scheduled-events" />

Creates a scheduled event in the Discord server (external location or channel) and records project ownership. Retrying with the same Idempotency-Key header returns the cached response without creating a duplicate event on Discord.

**Authentication:** Project API key (`X-API-Key` header)

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serverId` | path | `string` | yes | Discord server ID |
| `Idempotency-Key` | header | `string` | no | Optional idempotency key (up to 128 characters). A retry with the same key returns the cached response. |

**Request body** (JSON, required): [CreateScheduledEventDto schema](#createscheduledeventdto-schema).

**Responses**

| Status | Description | Body |
| --- | --- | --- |
| `201` | Scheduled event created successfully | `ScheduledEventResponseDto` |
| `400` | Invalid input payload, time range or entity parameters |  |
| `401` | Missing or invalid API key |  |
| `403` | Project lacks manage_events scope on this server |  |
| `404` | Server or channel not found |  |
| `409` | Idempotency conflict: a request with this key is currently in progress, or the key was reused with a different payload. |  |
| `429` | Project rate limit exceeded |  |
| `502` | Discord rejected the request or bot lacks permissions |  |

## Delete a Discord scheduled event

<Endpoint method="DELETE" path="/api/servers/{serverId}/scheduled-events/{eventId}" />
