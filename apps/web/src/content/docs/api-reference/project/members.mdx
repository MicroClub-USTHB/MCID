## Search members

<Endpoint method="GET" path="/api/servers/{serverId}/members" />

Search and filter members in a server with pagination. Requires the `read_members` scope granted for this specific server.

**Authentication:** Project API key (`X-API-Key` header)

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serverId` | path | `string` | yes | Discord server ID |
| `query` | query | `string` | no | Partial match on username, global name, or display name |
| `roleId` | query | `string` | no | Filter by Discord role snowflake ID |
| `page` | query | `number` | no | Page number (min 1) Default: `1`. |
| `limit` | query | `number` | no | Items per page (1-100) Default: `20`. |
| `isClubMember` | query | `boolean` | no | Filter by club membership status |
| `isActive` | query | `boolean` | no | Filter by active server membership status |

**Responses**

| Status | Description | Body |
| --- | --- | --- |
| `200` | Paginated list of matching members. | `object` |
| `400` | Invalid query parameters. |  |
| `401` | Missing or invalid API key. |  |
| `403` | Project does not have access to this server, or missing `read_members` scope for this server. |  |
