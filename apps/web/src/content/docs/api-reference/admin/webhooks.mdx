Discord webhook creation and management, authenticated with a project API key

## List a project's webhooks (admin session)

<Endpoint method="GET" path="/api/admin/projects/{projectId}/webhooks" />

Returns the webhooks owned by any project, in the same shape as the project-facing list. Channel and server names are resolved from the bot cache and may be null. Tokens are never returned.

**Authentication:** Admin session token (`Authorization: Bearer <token>`)

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
| `serverId` | query | `string` | no | Filter by Discord server ID |
| `limit` | query | `number` | no | Max number of webhooks (1-100) Default: `50`. |
| `offset` | query | `number` | no | Pagination offset Default: `0`. |

**Responses**

| Status | Description | Body |
| --- | --- | --- |
| `200` | The project's webhooks. | `WebhookListResponseDto` |
| `400` | Invalid project ID or query parameters. |  |
| `401` | Authentication required. |  |
| `403` | System Admin access required. |  |

## Delete a webhook (admin session)

<Endpoint method="DELETE" path="/api/admin/webhooks/{webhookId}" />

Deletes a webhook owned by any project, on Discord and then in storage. If Discord refuses, the stored webhook is kept.

**Authentication:** Admin session token (`Authorization: Bearer <token>`)

**Parameters**
