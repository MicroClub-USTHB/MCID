These endpoints serve the admin dashboard and are not meant for projects. They need an admin session, a system administrator signed in with Discord. The dashboard sends the session as a cookie; in Swagger you give it as a Bearer token.

The endpoints for projects are in the [Project API](/docs/api-reference/project/overview).
