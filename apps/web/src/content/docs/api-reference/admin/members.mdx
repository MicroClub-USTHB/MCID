## List members with optional server, role, filter and search criteria (paginated)

<Endpoint method="GET" path="/api/admin/members" />

Paginated list of members across managed servers. Supports filtering by serverId, roleId, filter=club|all, and search term.

**Authentication:** Admin session token (`Authorization: Bearer <token>`)

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter` | query | `"club" or "all"` | no | Filter type: "club" = only members in the main server, "all" = any managed server Default: `"all"`. |
| `serverId` | query | `array of string` | no | Discord server ID(s) to restrict results to members of specific server(s). Supports repeated params (?serverId=A&serverId=B) or comma-separated values (?serverId=A,B). |
| `roleId` | query | `array of string` | no | Discord role ID(s) to restrict results to members holding specific role(s). Supports repeated params (?roleId=A&roleId=B) or comma-separated values (?roleId=A,B). |
| `page` | query | `number` | no | Page number (1-based) Default: `1`. |
| `limit` | query | `number` | no | Number of items per page Default: `20`. |
| `search` | query | `string` | no | Search string to filter by username or global name |

**Responses**

| Status | Description | Body |
| --- | --- | --- |
| `200` | Paginated member list retrieved. | `PaginatedCrossServerListDto` |
| `400` | Invalid query parameters. |  |
| `401` | Authentication required. |  |
| `403` | System Admin access required. |  |

## Export members report

<Endpoint method="GET" path="/api/admin/members/export" />

## Get member cross-server view

<Endpoint method="GET" path="/api/admin/members/{discordId}/servers" />
