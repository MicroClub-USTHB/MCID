Manual sync triggering and sync log inspection - system admin only

## Trigger a full sync

<Endpoint method="POST" path="/api/admin/sync/full" />

Queues a manual sync for one or more servers. Use `target` to limit the sync to MEMBERS, ROLES, or ALL (default). Omit `serverIds` to sync all active servers.

**Authentication:** Admin session token (`Authorization: Bearer <token>`)

**Request body** (JSON, required): [TriggerSyncDto schema](#triggersyncdto-schema).

**Responses**

| Status | Description | Body |
| --- | --- | --- |
| `202` | Sync queued. | `any` |
| `400` | Invalid request body. |  |
| `401` | Authentication required. |  |
| `403` | System Admin access required. |  |
| `404` | Server not found. |  |
| `409` | Sync already queued or in progress. |  |

## Get paginated sync logs for a server
