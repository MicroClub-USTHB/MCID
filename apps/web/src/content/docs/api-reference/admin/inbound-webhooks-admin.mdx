## Create an inbound webhook

<Endpoint method="POST" path="/api/admin/inbound-webhooks" />

The schema is validated up front. Name the Discord roles that may read submissions, or omit `allowedRoleIds` to use the default reader roles (MC Executive unless changed in the settings). At least one role must result - unlike project_roles, an empty role set means nobody, not everybody. The signing secret is returned exactly once.
